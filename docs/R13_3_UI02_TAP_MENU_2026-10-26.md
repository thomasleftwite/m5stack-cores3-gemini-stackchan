# R13.3 UI02: 顔画面を1回タップして設定を表示

日付: 2026-10-26 JST。対象: COM10のCoreS3 Lite / ESP32-S3、PC USBのみ・Groveなし。
目的: 利用者の指定に従い、設定などの選択操作を待機顔画面への1回タップから開く。
正本: `C:/Users/thoma/SynologyDrive/H/Doc/Src/Codex/projects/ai-stackchan/m5stack-cores3-gemini-stackchan/firmware/`。

## 変更

- Readyの顔画面の任意位置を1回タップすると、既存の設定・呼びかけ登録メニューを表示する。
- 顔画面の右上の設定ボタンと青背景を廃止。通常の下部案内は「呼びかけ待ち / タップで設定」、未登録なら「タップして呼びかけを登録」。
- 設定へ入る際、前の「呼びかけを保存しました」等の通知を消し、メニューの説明を表示する。
- Sleepの最初のタップはReadyへの復帰だけ。設定から戻る操作、登録・取消・再試行の操作は維持。
- UI01のメニュー合成と同一画面再描画抑止を維持。D1の数値診断も維持し、録音・照合・保存・通信の分岐は変更しない。

## 成果物・依存・検証方法

`firmware/src/main.cpp`, `StackChanAvatar.cpp`, `StackChanAvatar.h`、`firmware/tools/test_display.py`。
配布とルートsrcは`tools/sync_firmware_sources.mjs`で同期する。
既存のespressif32@6.5.0 / Arduino-ESP32 2.0.14 / M5Unified 0.1.17 / M5GFX 0.2.32を維持。
MSVCとPythonで実main.cppのタッチ分岐・描画分岐・実Avatarをホスト実行し、PlatformIOでビルドする。
実機はアプリのみ更新し、ブートローダー・領域表・起動選択・NVS・FATを前後比較して保持する。
利用者がこの開発中のフラッシュを継続承認しているため、都度の再確認は不要。
