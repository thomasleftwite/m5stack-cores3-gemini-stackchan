# R13.3 UI03: Readyは顔だけ、操作表示はタップ後

日付: 2026-10-26 JST。対象: COM10のCoreS3 Lite、PC USBのみ・Groveなし。
目的: 利用者の仕様変更「readyは顔アニメーションのみ、ユーザー操作に関する表示は1回タップした後」に対応する。

仕様の正本は案件ルートの`docs/VOICE_PIPELINE_R13.md`。UI02の下部操作案内・設定遷移時の通知消去は本UI03仕様で更新する。以前の実機確認記録は保持する。

## 仕様と実装

- Readyは顔アニメーションだけ。登録の有無にかかわらず、文字・設定ボタン・操作案内を表示しない。
- 「呼びかけを保存しました」等の通知もReadyには描かずRAMに保持。顔画面の任意位置を1回タップして開く設定メニューに表示する。通知がなければ通常の登録説明を表示。
- 設定から戻ると顔だけに戻る。録音など別の状態からReadyへ戻った場合も前のステータス文字を消す。
- Sleepからの最初のタップはReady復帰だけ。録音・通信・再生・エラー画面などReady以外の表示、音声処理・保存・再試行・D1診断は維持する。
- ReadyではAvatarへ空のステータスを渡し、空の場合は文字描画を行わない。設定遷移時に通知を消去する処理を外す。

## 依存と確認手順

既存のespressif32@6.5.0 / Arduino-ESP32 2.0.14 / M5Unified 0.1.17 / M5GFX 0.2.32を維持。
MSVC + Pythonの実コード検査`firmware/tools/test_display.py`、PlatformIOビルド、配布同期、Web型検査を使う。
変更ファイルは`firmware/src/main.cpp`, `StackChanAvatar.cpp`、描画検査とスタブ、仕様・検証記録。ルートsrcと配布は同期ツールで正本へ合わせる。
利用者の開発中フラッシュ継続承認に基づき、`tools/flash_r13_ui_app.py`でアプリ1画像だけを0x10000へ更新する。
ブートローダー・領域表・起動選択・NVS・FATを前後比較し、設定・登録・Wi-Fiを保持する。秘密領域の内容・ハッシュを記録しない。
