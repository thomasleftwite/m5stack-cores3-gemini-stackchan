# CoreS3 FAT対応・全体書込み R13.3

日付: 2026-10-25 JST。目的: 利用者が許可した「現在のアプリ最新版で全体をフラッシュ」を実施する。
対象: COM10のESP32-S3/CoreS3、PC USB給電、Grove/外部電源なし（同日の確認済み構成）。起点30f7c0d。
選定済みのアプリ3MiB×2/FAT9.875MiBを有効化し、STT3.1/回答3.5 Flash-Lite/TTS3.8 Liteを維持する。

## 許可と書込み範囲

今回の全体書込みはブートローダー・領域表・起動選択・アプリ・FAT保存域の初期化を含む。
事前に会話でも保存域置換と呼びかけ再登録の前提を案内した。既存保存域のファイルを保持する方式ではない。
ローカルの準備済みconfig.jsonを非公開FATイメージへ含める。NVSのWi-Fi設定は更新範囲から外す。

| 範囲 | 開始位置 | 用途 |
|---|---:|---|
| bootloader.bin | 0x0000 | 起動ローダー |
| partitions.bin | 0x8000 | 選定CSVと同じ領域表 |
| boot_app0.bin | 0xe000 | app0を初期起動先にする起動選択 |
| firmware.bin | 0x10000 | R13.3、最大3MiB |
| FAT消去 | 0x610000 / 0x9e0000 bytes | 全体書込みに伴う保存域初期化 |
| fatfs.bin | 0x611000 | 先頭1セクタをWear Levelling用に空け、残りを標準mkfatfs画像で作成 |

NVS=0x9000/0x5000は上記のどの消去・書込み範囲にも含まない。前後のNVS比較はRAM上だけで行い、内容・ハッシュ・生ダンプを保存しない。
FATイメージと実config.jsonはGit除外されたfirmware/.pio/とfirmware/data/config.jsonで扱い、共有配布へ含めない。FAT画像の秘密由来ハッシュも記録しない。

## 実装

- firmware/partitions/cores3_16mb_app3m_fat9m.csvを固定し、platformio.iniのCSV/FSを選定したFAT配置へ変更。
- LocalStorage.hからFFat.begin(false)と共通FSを提供。最大同時オープン2件に絞り、FAT用内部RAMを抑える。マウント失敗時の自動フォーマットはしない。
- ConfigManagerとLocalWakeを同じFSへ変更。登録の2世代/一時ファイル/CRC処理は維持。
- 設定初期作成では短い書込みを成功扱いにしない。既存configのキー/本文はログへ出さず、読込み成功とキー設定有無だけを記録。
- 起動ログにR13.3、FATマウント、登録有無、ready到達を追加。記録ツールは許可した状態だけを出力する。
- 配布ツールへpartitions/を追加し、ルート側にも同じCSVを同期。

## 依存と再現手順

PlatformIO espressif32@6.5.0、Arduino-ESP32 2.0.14、M5Unified0.1.17、M5GFX0.2.32、ArduinoJson7.4.3、WiFiManager2.0.17を維持。
FS生成は既存のtool-mkfatfs2.0.1。書込みは固定済みesptool4.5.1とPlatformIO同梱Python/pyserialを使用。
FATの+4096オフセットはこの版のPlatformIO builder/main.pyと[アップローダーの一次説明](https://github.com/lorol/arduino-esp32fatfs-plugin#notes-for-fatfs)に従う。

```powershell
./firmware/tools/run_offline_tests.ps1
node tools/sync_firmware_sources.mjs
node node_modules/typescript/bin/tsc --noEmit --incremental false
# firmware/で、固定済みPlatformIOによりrunとrun -t buildfs
# 案件ルートで、PlatformIO同梱Pythonにより以下を実行
python -B tools/flash_r13_full.py --inspect
python -B tools/flash_r13_full.py --preflight --port COM10
python -B tools/flash_r13_full.py --execute --port COM10
python -B tools/observe_r13_boot.py --port COM10 --reset --seconds 45
```
