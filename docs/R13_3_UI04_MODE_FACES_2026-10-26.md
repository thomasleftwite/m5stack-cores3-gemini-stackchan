# R13.3 UI04: モード別の表情

日付: 2026-10-26 JST。対象: COM10のCoreS3 Lite、PC USBのみ・Groveなし。
目的: ランダムな録音開始・短時間での終了を利用者が見分けられるよう、まず状態ごとに顔を区別する。
正本: `C:/Users/thoma/SynologyDrive/H/Doc/Src/Codex/projects/ai-stackchan/m5stack-cores3-gemini-stackchan/firmware/`。

## 表示仕様

| 表示モード | 内部状態 | 表情 |
|---|---|---|
| Sleep | Sleep | 閉じた目。輝度18の薄暗い顔を1回描いて保持 |
| Ready | Ready | 白い通常の目、まばたき、小さな閉じた口。文字なし |
| Listening | Cue / Recording | 水色の大きな目、上がった眉、閉じた小さな口 |
| Thinking | Busy（STT/回答/TTS） | 黄色の細めの目、上向きに動く視線、小さな丸い口 |
| Speaking | Speaking | 緑の目、持ち上がった眉、再生音量に連動して動く口 |

表示はモードを優先し、応答本文の感情をそのまま顔へ流用しない。サーボの既存感情処理は変更しない。
モード切替時に視線・まばたき・口の補間をリセットし、Thinkingの視線やSleepの閉眼がReadyへ残らないようにする。
設定/登録/エラー等のメニュー操作は既存画面を使う。Readyの1回タップで設定を開くUI03の仕様を維持。
Sleepを薄暗い眠り顔にすることは利用者が選択済み。Sleepのタップは顔のReady復帰だけ。

## 成果物・依存・再現

- `firmware/src/StackChanAvatar.h/.cpp`: 表示モード、表情と色、口の連動。
- `firmware/src/main.cpp`: 内部モードと顔の対応、Sleepの低輝度表示。
- `firmware/tools/test_display.py`と`firmware/tests/display_stubs/M5Unified.h`: 実タッチ/描画コードの検査、実描画コマンドの書出し。
- `firmware/tools/render_face_preview.ps1`: 実描画コマンドからWindows System.Drawingで比較画像を生成。LCDの実輝度や画素単位の一致の証明ではない。
- `docs/validation/ui04-face-modes/face-modes.png`: 5つの顔の比較画像。

既存のespressif32@6.5.0 / Arduino-ESP32 2.0.14 / M5Unified 0.1.17 / M5GFX 0.2.32を維持。
PC検査はMSVC + Python、比較画像はWindows PowerShell/System.Drawing。音声・認識文は比較画像に含まれない。
開発中フラッシュの継続承認に従い、アプリだけ更新し、設定・登録・Wi-Fiと起動用領域を前後比較で保持する。
